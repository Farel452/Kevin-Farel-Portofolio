Featured Works

Spojeday

SpoJeDy is a Spotify-inspired music web app built with my group as part of a university project. It presents a song catalog in a clean grid layout album art, title, artist, and duration alongside a separate section for videos. The design leans into Spotify's familiar dark theme with green accents, giving it a recognizable yet distinct visual identity.

VueTypeScriptCSS

ApexMoto

Apex Motor is a UI/UX prototype for a web-based marketplace built for buying and selling big motorcycles (moge). The project was designed as a digital solution that brings a more structured and trustworthy experience to moge transactions. It includes a digital showroom feature that lets sellers present their listed units in a more professional way. A social media-style feature is also built in, so sellers can maintain the personal, relationship-driven approach they're used to on platforms like Instagram, TikTok, and Facebook.

UI/UXFigmaWeb

Laundry Management System

Laundry Service Management System is a Java-based desktop application built with my group to manage laundry business operations end-to-end, from order intake to delivery. It covers customer data management, order entry with automatic price calculation, real-time production status tracking, and delivery scheduling all tied together in a single statistics dashboard. It's built with Java Swing for the interface and MySQL as the database, following an MVC architecture with the DAO pattern to keep the codebase structured and maintainable.
